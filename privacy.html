プライバシーポリシー

イベントボード（以下「本サイト」）が扱う情報について説明します。

最終更新：2026年8月10日

1. 収集しない情報

本サイトは会員登録・ログインの仕組みを持ちません。氏名・メールアドレス等の個人情報を入力していただく画面はありません。

アクセス解析ツールおよびCookieを使用していません。閲覧履歴の記録・追跡は行いません。

2. 位置情報

「現在地から近い順にならべる」または地図の「現在地へ」を押したときだけ、ブラウザの位置情報機能で座標を取得します。

取得した座標は、ご利用の端末の中だけで距離の計算に使用します。外部への送信・サーバーへの保存は行いません。座標をどこかへ送る処理は、本サイトの作りとして存在しません。ページを離れると保持されません。

3. 端末内に保存される情報

「行きたい」に登録した内容は、ブラウザの localStorage に保存されます。絞り込みの状態はURLに保持されます。

これらも端末の中だけに保存され、外部へは送信されません。ブラウザの設定から削除できます。

4. 第三者へ送信される情報

本サイトの表示にあたり、次の情報がそれぞれの提供元へ送信されます。いずれも運営者が受け取るものではありません。

送信先 送信されるもの いつ
Google（Google Fonts） IPアドレス、ブラウザの情報 すべてのページの表示時（画面のフォントを読み込むため）
OpenStreetMap Foundation IPアドレス、表示している地図の範囲 「地図で範囲をえらぶ」「会場」の地図を開いたときだけ
Google（Googleカレンダー） イベント名、説明、URL 「Googleカレンダーに追加」を選んだときだけ

Google Fonts と地図タイルは、本サイトが自前で配信していない外部の資源です。読み込めなくても、一覧の表示と絞り込みは動作します。

5. サーバーログ

本サイトは GitHub Pages で配信しています。アクセスログの取得・保管は GitHub 社の方針に従います。運営者はこれを参照しません。
